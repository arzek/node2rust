# lessons/000-hello-world Specification

## Purpose

Урок 0 курсу «Rust для Node.js-розробника»: перша програма на Rust і перший повний цикл уроку — прочитати README, дописати код, отримати зелені тести однією командою.

## Requirements

### Requirement: Склад уроку
Папка `lessons/000-hello-world/` MUST містити `README.md`, стартовий код програми й готові тести. Репозиторій MUST NOT містити розв'язку завдання — ні в папці уроку, ні в артефактах зміни.

#### Scenario: Учень відкриває урок
- **WHEN** учень відкриває `lessons/000-hello-world/`
- **THEN** він бачить `README.md`, стартовий код програми й тести, а коду, який проходить тести, у репозиторії немає

### Requirement: README на один екран
`README.md` уроку MUST мати не більше 40 рядків і містити п'ять частин: теорію на 3–5 речень, приклад коду, порівняння з TypeScript/NestJS, завдання й команду для перевірки. Пояснення MUST бути українською, код і коментарі в коді — англійською.

#### Scenario: Обсяг і структура
- **WHEN** учень відкриває `README.md`
- **THEN** у файлі не більше 40 рядків і є всі п'ять частин

#### Scenario: Зміст теорії та порівняння
- **WHEN** учень читає теорію й порівняння
- **THEN** README пояснює призначення `Cargo.toml` і `src/main.rs`, роль `fn main` і `println!`, різницю між `cargo run` і `cargo test` та називає їхні відповідники з Node.js/NestJS

#### Scenario: Приклад не є розв'язком
- **WHEN** учень переносить приклад коду з README у програму без змін
- **THEN** тести уроку лишаються червоними

#### Scenario: Команда з README працює дослівно
- **WHEN** учень виконує команду для перевірки так, як вона записана в README
- **THEN** запускаються тести уроку 0

### Requirement: Стартовий код червоний з правильної причини
Стартовий код MUST компілюватися без помилок і попереджень, а тести на ньому MUST падати саме через відсутність привітання у stdout, а не через помилку компіляції.

#### Scenario: Перший запуск тестів
- **WHEN** учень запускає тести, нічого не змінивши в уроці
- **THEN** код компілюється, тест на вивід падає й показує очікуваний рядок `Hello, world!` поруч із фактичним порожнім виводом, а команда завершується з ненульовим кодом

### Requirement: Тести приймають лише точне привітання
Тести уроку MUST бути зеленими тоді й лише тоді, коли програма друкує у stdout рівно один рядок `Hello, world!` із символом нового рядка в кінці, нічого не пише в stderr і завершується з кодом 0. Щоб виконати завдання, учень MUST змінювати лише код програми — не тести й не маніфест.

#### Scenario: Правильний розв'язок
- **WHEN** учень змінив лише код програми, і вона друкує у stdout рівно `Hello, world!` з новим рядком, нічого не пише в stderr і завершується з кодом 0
- **THEN** усі тести уроку зелені

#### Scenario: Інший текст
- **WHEN** програма друкує привітання з іншим регістром, пунктуацією або зайвими рядками
- **THEN** тест на вивід падає й показує різницю між фактичним і очікуваним рядком

#### Scenario: Без нового рядка
- **WHEN** програма друкує `Hello, world!` без символу нового рядка в кінці
- **THEN** тест на вивід падає

#### Scenario: Привітання в stderr
- **WHEN** програма пише привітання в stderr замість stdout
- **THEN** тести падають

#### Scenario: Ненульовий код завершення
- **WHEN** програма друкує правильне привітання, але завершується з ненульовим кодом
- **THEN** тести падають

### Requirement: Перевірка однією командою
Урок MUST перевірятися командою `cargo test`, запущеною з папки уроку. Запуск MUST виконувати лише тести цього уроку й MUST працювати без мережі та зовнішніх залежностей.

#### Scenario: Запуск із папки уроку
- **WHEN** учень виконує `cargo test` у `lessons/000-hello-world/`
- **THEN** виконуються лише тести уроку 0, а результат відповідає стану завдання: червоний до розв'язку, зелений після

#### Scenario: Без мережі
- **WHEN** мережа недоступна
- **THEN** `cargo test` так само збирає й запускає тести уроку

### Requirement: Збірка не засмічує git
Артефакти збірки MUST NOT потрапляти в git: після збірки, запуску й тестів уроку git не показує згенерованих каталогів збірки.

#### Scenario: Після запуску й тестів
- **WHEN** учень виконав `cargo run` і `cargo test`
- **THEN** `git status` не містить каталогу `target/`
